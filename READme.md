## 🏗 Архитектура системы

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   Client    │────▶│ API Gateway │────▶│ User Service│
│             │     │   :8000     │     │   :8001     │
└─────────────┘     └─────────────┘     └─────────────┘
                          │                    │
                          ▼                    ▼
                   ┌─────────────┐     ┌─────────────┐
                   │Call Service │     │PostgreSQL   │
                   │   :8002     │     │   :5432     │
                   └─────────────┘     └─────────────┘
                          │                    │
                          ▼                    ▼
                   ┌─────────────┐     ┌─────────────┐
                   │Call Provider│     │    Redis    │
                   │   :8003     │     │   :6379     │
                   └─────────────┘     └─────────────┘
                          │
                          ▼
                   ┌─────────────┐
                   │Logging Serv.│
                   │   :8004     │
                   └─────────────┘
```

### Компоненты системы

| Компонент | Порт | Технологии | Назначение |
|-----------|------|------------|------------|
| **API Gateway** | 8000 | FastAPI, HTTPX | Единая точка входа, маршрутизация, авторизация |
| **User Service** | 8001 | FastAPI, SQLAlchemy | Управление пользователями (CRUD) |
| **Call Service** | 8002 | FastAPI, Redis, SQLAlchemy | Обработка звонков, кэширование |
| **Call Provider** | 8003 | FastAPI, HTTPX | Внешний провайдер (симуляция) |
| **Logging Service** | 8004 | FastAPI, Logging | Централизованное логирование |
| **PostgreSQL** | 5432 | PostgreSQL 15 | Персистентное хранение |
| **Redis** | 6379 | Redis 7 | Кэширование истории звонков |

## 🚀 Быстрый старт

### Требования

- Docker Desktop (версия 24.0+)
- Docker Compose (версия 2.20+)
- Python 3.11+ (для локального запуска тестов)
- 4GB свободной оперативной памяти
- curl или Postman (для тестирования API)

### Установка

1. **Клонируйте репозиторий**
```bash
git clone https://github.com/your-username/domofon-broker.git
cd domofon-broker
```

2. Настройте окружение
```bash
cp .env.example .env
```

3. Запустите систему
```bash
docker compose up --build
```

4. Проверьте работу сервисов
```bash
docker compose ps
```

## Задание

Починить систему так, чтобы:
1. Пользователи создавались и сохранялись в PostgreSQL
2. Звонки инициировались и записывались в историю
3. Работал Redis-кэш для быстрого доступа к истории
4. Все сервисы логировали события в Logging Service
5. API Gateway проверял авторизацию (JWT Bearer токен)
6. Работали все юнит-тесты (написать недостающие)
7. Проходил интеграционный тест

## Известные проблемы (не все!)

- Сервисы не видят друг друга в Docker
- Нет commit() в базу данных
- Кэш Redis использует неправильные ключи
- API Gateway не проверяет авторизацию
- Call Provider не может достучаться до Call Service

## Исправленные проблемы

1. **User Service пишет в Logging Service** — при создании пользователя отправляется событие в logging_service
2. **Call Service сохраняет звонок в PostgreSQL** — звонки сохраняются в БД
3. **Call Provider достукивается до Call Service** — исправлены URL в docker-compose.yml (localhost -> Docker service name)
4. **Redis Cache ключи формируются правильно** — ключ `history:{user_id}` вместо `history`
5. **API Gateway валидирует авторизацию** — проверка JWT токена, без токена 401
6. **Observer паттерн для уведомлений** — при звонке отправляется notification в logging_service
7. **User Service проверяет уникальность телефона** — дубликаты возвращают 400
8. **Logging Service добавляет timestamp** — время события включено в логи
9. **API Gateway имеет rate limiting** — не больше 10 запросов в секунду
10. **JWT авторизация** — полноценная JWT с истечением через 30 минут

## Проверка работоспособности

### 1. Получить JWT токен
```bash
curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'
```

### 2. Создать пользователя
```bash
curl -X POST http://localhost:8000/users \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"phone":"+79991234567","name":"John"}'
```

### 3. Инициировать звонок
```bash
curl -X POST http://localhost:8000/call/initiate \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"user_id":1}'
```

### 4. Получить историю звонков
```bash
curl http://localhost:8000/history/1 \
  -H "Authorization: Bearer <token>"
```
